# Popular Pharma homepage (v2)

Open `index.html` in a browser. No build step. Plain HTML, CSS and JS.

## Files
- `index.html` page structure and copy
- `styles.css` all styles, responsive at 1080, 960 and 640 px
- `main.js` mobile menu, product finder, side effect form, scroll reveal
- `images/` photos from the current popular-pharma.com site

## Where the ideas came from
- Novartis: quiet, large headline on white. One full-width photograph for manufacturing.
- Roche: headline and two buttons left, real photo right. Calm top navigation. Therapeutic areas as a plain list. News as editorial rows.
- BioNTech: slim utility bar with "Report a side effect". Pill buttons with arrows. Big full-width colour panels for the insulin story and export.
- Vertex: restraint. Numbers set in type on thin rules, no cards.

## Rules kept
- Blue #32348a for buttons with white text. Green #009749 for fills and large type. Small green text uses #00733a.
- Body text 18px. Newsreader for headlines, Public Sans for reading.
- Motion: gentle rise on scroll and a slow photo reveal. Turns off with reduced motion.
